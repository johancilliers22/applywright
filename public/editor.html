Contact

One item per line. A phone number that does not start with + is written with a Phone: label on save, because that is what keeps it in the contact block when the server reads the text back.

Summary

Two or three sentences. The analyser reads it and the pack prints it.

Experience

Role lines stay as they are. Lines that start with -, * or a number are the bullets the assistant may rewrite.

Education

Qualification, institution and dates. These are facts the assistant may not change.

Skills

A comma-separated list reads best to the analyser. Empty sections are left out of the saved text.

Other

Projects, certifications, languages, awards — whichever the parser could not place above. Leave it empty to leave it out.

    Add data from sources

    Nothing here is fetched for you. Every source is text you paste, or a file you pick yourself.

    Paste a LinkedIn profile

    LinkedIn does not let other applications read your profile, so there is no sign-in button to offer. Copy the profile text from the browser where you are already signed in — or use your own PDF export — and paste it below. Applywright never signs in to LinkedIn, uses no OAuth, and never fetches the page.

    Paste an advert

    Paste the advert and see which of its keywords this CV already covers, measured by the same rubric the score uses. Nothing is stored.

    Upload a file

    PDF, DOCX, Markdown and plain text are read in the CV library's ingest drawer, which is also where a new CV is created. This page edits a CV that already exists, so the upload route is a link rather than a second copy of the same form.

    Open the ingest drawer

    It opens the library with the drawer expanded; choose “Upload a file”, then come back here with the new CV selected.

    What this page will not do

    • It does not apply a proposal for you. Accepting a hunk is a click; saving is a second one.
    • It does not invent an employer, title, qualification, date or number, and it rejects a proposal that does.
    • It does not fetch LinkedIn, or any other page. You paste; it reads.
    • It prints a single-column A4 document. Two-column CV designs are out of scope on purpose.
