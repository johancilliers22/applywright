# Operator repair contract: complete claim records

1 November2026. Architecture direction for the next explicitly released source
successor. This does not launch a writer or change any oracle. Finish the ready
R12 diagnostic opportunity first; preserve every frozen candidate and result.

The R12 review demonstrates that another head/overlap/prefix-word exception
preserves the same underlying failures. Required final behavior is unchanged:
facts must be supported in the source, with useful faithful rewriting retained.
Use an occurrence-bound claim representation rather than adding further pooled
exemptions for the latest literal example.

Each factual record must retain source offsets and its actor, governing predicate,
complete subject/object with modifiers, polarity, factual/application modality,
typed value/unit/currency/period and relevant association/relation. Not every
record uses every field; absence is explicit and cannot mean a wildcard. Target
support must come from ONE compatible record or an explicitly justified shared
coordination/list record, never fields assembled from unrelated occurrences.

1. Actor scope: a first-person subject wins only for its own governing predicate.
   Track relative/embedded spans so the I in 'My colleague, whom I supported,
   worked...' does not become the actor of worked. Genuine 'my colleague and I
   worked' includes the candidate. Dated header shape does not prove ownership.
2. Skill/list scope: bare permitted candidate lists and explicit candidate-owned
   skill headers are valid evidence. Her/his/their/colleague-owned records are
   other-actor evidence. Normalize terminal punctuation separately from names.
3. Technology association: affirmative with/using/based-on relations must attach
   to the same complete object, or an explicitly permitted candidate-owned skill
   record. 'without Azure' is negative evidence. Technology on a team's APIs,
   another clause or another actor cannot silently become service technology.
4. Complete measure subject: response latency and request latency are different
   records despite a common latency/API head. Eliminate any-token/head-overlap
   acceptance fallback for factual associations. A target that drops a qualifier
   may be less specific; a target replacing that qualifier is not supported.
5. Genuine shared measures: represent each coordinated subject assigned the
   single shared value. Preserve faithful splitting/reordering without treating
   every conjunction as a boundary or a whole-clause value pool.
6. Money occurrence: bind actor, complete claim/subject, currency, value and period
   together. Equal project/travel costs or She/I savings cannot exchange periods.
   An empty subject cannot bypass matching. An ungoverned clause never inherits
   a preceding clause's ownership level just because its number matches.
7. Governed event/object: participial and prepositional adjuncts do not overwrite
   the main object head. A workshop held at Azure remains an event, not candidate
   employment. Preserve the explicitly reviewed workshop-team company positive.
8. Explicit factual slots dominate vocabulary: 'my employer is knowledge' and
   'skills is my employer' still contain employer claims. Trim ordinary language
   only inside an actual grammatical complement, not out of an explicit name slot.
9. Canonical units: all digit/spelled/shape callers produce the same typed form,
   percent flag, plural-normalized lexical unit and period. Annually is a period,
   not an opaque numeric-tail unit. Preserve distinct counts/currency/dimensions.
10. Unknown support: do not turn an unparsed role or missing association into an
    automatic acceptance. Return a precise conservative refusal where unsupported;
    retain the old faithful211/76/29/140 controls and useful generalizations. A
    reject-all/model-off solution, rewritten expectations or hard-coded witnesses
    does not meet the contract.

Keep the intentional asymmetry: tailor permits supported omission; refine's
no-dropped-metric coverage is occurrence-aware and must not erase duplicates by
reducing them to a value set. Existing entity/date/qualification/currency and
schema/index defenses remain until the corresponding record comparison replaces
them with equal-or-stronger behavior and all meaningful controls demonstrate it.

Implement inside the assigned four core files only unless a separately reviewed
module extraction is expressly assigned. Prefer one canonical construction path
per kind to duplicated callers with incompatible flags; no unrelated rewrite.
Append mechanism-based faithful/adverse tests, including the review witnesses
and nonliteral combinations; preserve every old assertion and the840ms disposition.
Report any genuinely ambiguous construction honestly. Source writing performs
no imports/parsers/tests. Independent Sol review and new exact actual focused,
independent and full required gates still precede acceptance and main integration.
